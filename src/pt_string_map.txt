# The original sometimes pushes a string *literal* (reccmp shows a STRING
# entity) and sometimes a data *array* copy of the same text (our 0999
# scaffold, shown as DATA).  Our side must reference the same kind of symbol
# or the operand names differ even though the bytes are identical.
#
# Applied by tools/patch_obj_syms.py at link time:
#  * an undefined reference (our raw naked asm) is renamed in the object;
#  * a reference to a literal defined in the same object (compiled STL code)
#    has its relocation repointed to the scaffold symbol, which is added as an
#    undefined reference (the LNK1179-safe path).
